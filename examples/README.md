# Examples, Experiments, and Notebooks

This directory contains small practical demonstrations that complement the theory notes.

## Structure
- `python/` — standalone scripts and worked examples
- `notebooks/` — exploratory Jupyter notebooks
- `visualizations/` — plots and generated diagrams

Every example should include its purpose, prerequisites, run instructions, expected output, and limitations. Do not commit API keys, private data, unlicensed datasets, or large generated outputs. Use fixed random seeds when reproducibility matters.
